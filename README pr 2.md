# Logic Box

A menu-driven Python console program that demonstrates core programming concepts: loops, conditionals, lists, and control statements (`break`, `continue`, `pass`).

## Features

1. **Pattern Generator**: Prints a right-angled triangle of stars for the number of rows you enter.
2. **Number Analyzer**: Takes a starting and ending number, then lists the even numbers, the odd numbers, and the sum of all numbers in that range.
3. **Control Statements**: Demonstrates how `break`, `continue`, and `pass` behave inside `while` loops.
4. **Exit**: Closes the program.

The menu keeps running until you choose option 4.

## Concepts Covered

- `while` loops
- `if` / `elif` / `else` conditions
- Lists and `append()`
- User input with `input()` and type conversion with `int()`
- `break`, `continue`, and `pass` statements
- Basic input validation (positive rows, valid range, valid menu choice)
